## 🚀 How to Run Locally

### 1. Navigate to the project directory:
```bash
cd c:/Users/sruth/POC/homestay-web
```

### 2. Install dependencies (if not already installed):
```bash
npm install
```

### 3. Start development server:
```bash
npm run dev
```

### 4. Build for production:
```bash
npm run build
```
